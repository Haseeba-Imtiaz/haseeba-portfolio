# Portfolio Website

Hey there! 👋 Welcome to my personal portfolio project. This is a dynamic, fully responsive web application built with *ASP.NET Core MVC*. It showcases my projects, skills, and background in web development and data analytics.

## 🌐 Live Preview
You can check out the live working site hosted here:  
👉 *[haseeba-portfolio.runasp.net](http://haseeba-portfolio.runasp.net)*

---

## 🛠️ What I Used (Tech Stack)
* *Backend:* C# / ASP.NET Core MVC
* *Frontend:* HTML5, CSS3, JavaScript, Bootstrap
* *Hosting:* MonsterASP.net (IIS Server)
* *Tools:* Visual Studio Code, Git, GitHub

---

## ⭐ Key Highlights
* *Clean Architecture:* Standard MVC structure with separate models, custom controller logic, and Razor views.
* *Responsive Layout:* Formatted nicely across desktop, tablet, and mobile screens.
* *Interactive Pages:* Includes dedicated sections for projects, skills, contact form, and bookings/reservations.

---

## 💻 Running it Locally

If you want to pull the code and run it on your machine:

1. *Clone the repo:*
   ```bash
   git clone https://github.com/Haseeba-Imtiaz/haseeba-portfolio.git
   ```
**Open the project folder:**
```bash
cd haseeba-portfolio
```
**Build & Run:**
```
dotnet restore
dotnet run
```
